# ⚓ AZUR LANE · 指挥官的港口小站

碧蓝航线风格的二次元个人网站。纯 HTML/CSS/JS，零依赖。

## 🦄 特色
- **独角兽 C 位**：首页 Hero 中央为独角兽高清立绘（引用碧蓝航线 BWIKI 官方图床），带旋转光晕、悬浮动画与 HUD 取景框；另有独立的「最喜欢的舰船 · 独角兽」专区（介绍 + 属性条 + 皮肤画廊，点击皮肤可切换首页立绘）。
- **军事科技风 UI**：深海蓝背景、青色霓虹、切角面板、雷达网格、Orbitron 军用字体。
- **动效**：海光气泡粒子、打字机台词轮播（独角兽语音）、点击迸发 ✦🦄⚓ 特效、滚动进场与技能条填充。
- **板块**：母港 / 独角兽 / 关于指挥官 / 技能装备 / 舰船图鉴（企业、拉菲、绫波、海伦娜等官方立绘）/ 作战日志 / 电波通讯。
- 响应式布局，移动端汉堡菜单。

## 🚀 预览
```bash
cd /workspace && python3 -m http.server 8090
# 打开 http://localhost:8090
```
